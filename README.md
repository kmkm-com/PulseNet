interactive engagements (likes and comments), community groups, and automated notifications.This project is built for the DBMS Course Project to demonstrate clean relational database design, integrity enforcement, complex multi-table queries, and seamless full-stack integration using the PERN Stack.🛠️ Technology StackFrontend: React.js (Vite, Context API / Axios)Backend Layer: Node.js & Express.js ArchitectureThe system features 9 core relations designed up to 3NF / BCNF compliance:users: Secure credential isolation (user_id, username, email, password_hash).user_profiles: 1:1 weak entity storing public metadata (bio, location, avatar_url).friendships: Self-referential M:N relation managing connection states (pending, accepted, declined).posts: Core content storage with domain-level privacy constraints (public, friends_only, private).post_likes: M:N associative entity preventing duplicate likes via composite primary key (user_id, post_id).comments: Post engagement supporting self-referential parent/child comment threads.groups: Community hubs created by users with foreign key cascade definitions.group_members: M:N associative entity enforcing role hierarchy (admin, member).notifications: System alerts triggered by social interactions.🔄 Core Application WorkflowsUser Authentication & Profile Setup (Transactional):Registers new account credentials in users and initializes linked metadata in user_profiles within an atomic database transaction.Social Connection Request Flow (Graph Management):Handles bidirectional friendship logic (INSERT request $\rightarrow$ UPDATE status), controlling mutual access permissions.Personalized Feed Generation (Complex Retrieval):Executes multi-table joins (posts, users, friendships, post_likes) to compile feeds showing public posts and accepted connections' updates.🚦 Current Mid-Sem Progress Summary[x] Database Schema: Formulated ER/EER model, mapped relational schema, and written initial PostgreSQL DDL
